# @sentinel-official/ai-linux-x64

Platform-specific binary for [`@sentinel-official/ai`](https://www.npmjs.com/package/@sentinel-official/ai) on linux-x64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @sentinel-official/ai
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.
