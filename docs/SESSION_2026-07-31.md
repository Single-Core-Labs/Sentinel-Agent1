## Key gotchas learned this session (important for resume)

- **Ollama tag:** only `qwen3:latest` + `mistral:7b-instruct-v0.2-q5_0` exist; `qwen3:8b` → 404. Use `qwen3:latest`.
- **Windows cmd + args:** don't append tool_name/args as argv to `cmd /C echo ...` — echo prints everything. Policy contract uses **stdin** for data; hook contract uses argv (event + tool name) but reads JSON from stdin.
- **`tokio::time::timeout` on blocking `std::process::Command::output()` does NOT work** (E0277) — must use `tokio::process::Command` + `spawn()`/`wait_with_output()`. Fixed in both `event_bus.rs` and `script.rs`.
- **UTF-8 BOM breaks .cmd files** — write hook/policy scripts with `Set-Content` (no `-Encoding UTF8`), else `'﻿@echo' is not recognized`.
- **`--force` doesn't exist on `plugin install`** — use `plugin remove <id>` then install.
- **TS TUI needs** `bun run --jsx-import-source=@opentui/solid packages/cli-agent/src/index.tsx` (bun ignores tsconfig `jsxImportSource`).
- **`SENTINEL_NON_INTERACTIVE=1`** + `--prompt` runs headless (no TUI, no WS server) — used for all smoke tests.
- **`SENTINEL_HOME`** overrides plugin/session dirs; session test dir was `%TEMP%\sentinel-smoke\home`.
- Smoke artifacts (guard plugin, policy.cmd) live in `%TEMP%\sentinel-smoke\` — delete freely.
